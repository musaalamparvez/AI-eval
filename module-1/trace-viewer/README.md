# Cartwheel Trace Viewer

A single-page viewer for `hw1-session.jsonl`. Open `index.html` in a browser.

- Loads the 17 bundled HW1 records on open.
- Load another `.jsonl` file with the button, by drag and drop, or by pasting.
- Shows a first-run vs after-fix summary, a fix log, filters, the tool-call timeline
  for each conversation, and a side-by-side compare for before/after pairs.

The bundled data is a snapshot of `../hw1-session.jsonl` at the time of this commit.
